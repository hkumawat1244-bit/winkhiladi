# 💕 Do You Love Me?

Ek cute romantic web page jisme ek teddy bear puchta hai — **"Do you love me?"**

![Preview](preview.png)

---

## ✨ Features

- 🐻 Cute teddy bear stickers
- 💖 **"No" button bhaag jaata hai** — click karne nahi deta 😂
- 🥰 "Yes" click karne par dil burst animation
- 🌸 Floating petals background mein
- 💗 Beating heart animation
- 📱 Mobile friendly

---

## 📁 Files

```
├── index.html   → Main page
├── style.css    → Styling & animations
├── script.js    → Interactivity (No button escape, heart burst)
└── README.md    → Yeh file
```

---

## 🚀 GitHub Pages pe Deploy kaise karein

1. **Repository banao** — GitHub pe new repo create karo
2. **Teeno files upload karo** — `index.html`, `style.css`, `script.js`
3. **Settings → Pages** mein jao
4. **Source** mein `main` branch select karo
5. **Save** karo — kuch minutes mein live! 🎉

Live URL milega:
```
https://your-username.github.io/repo-name/
```

## 🎮 Kaise Kaam Karta Hai

| Action | Result |
|--------|--------|
| **"Yes"** click karo | Dil burst + "I knew it! 🥰" screen |
| **"No"** pe mouse le jao | Button bhaag jaata hai 😂 |
| Mobile pe touch karo "No" | Woh phir bhaag jaata hai 😂 |
